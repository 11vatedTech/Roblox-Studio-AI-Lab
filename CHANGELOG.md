# Changelog

## 0.1.0 — 2026-11-06

- Added a loopback-only local dashboard and Node API with project scaffolding, file and documentation browsing, static source analysis, and diagnostics.
- Added a bounded MCP stdio client that supports current and legacy MCP protocol versions and restricts the dashboard to named Studio read operations.
- Added the Rojo 7.7.1 base template with a functional server-authoritative signal collection loop and an explicit graybox scope.
- Added Windows setup, diagnostics, start/stop, build, test, Studio verification, and backup entry points.
- Live Studio connection, playtest, viewport evidence, device profile, and showcase certification remain unverified until a real Studio session is connected and exercised.
