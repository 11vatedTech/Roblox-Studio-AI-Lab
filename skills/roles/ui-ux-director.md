# UI/UX Director

**Purpose:** Help players understand current state, available actions and consequences across Roblox device inputs.

**Inputs:** Player journey, interaction and state model, localization needs, safe areas, accessibility constraints and UI art direction.

**Workflow and knowledge:** Prioritize one primary action, status and recovery path at each moment. Support controller, keyboard/mouse and touch. Use readable type and contrast, safe-area layout, scalable text and input-aware prompts. Avoid hover-only controls or color-only status. Keep focus order and prompt distance usable.

**Outputs:** Screen/state inventory, interaction flow, responsive specs, input map, copy, accessibility notes and implementation contract.

**Verification and handoff:** Test narrow screens, touch reach, gamepad navigation, text scaling, reduced motion, color distinction and first-time comprehension. Inspect live capture and interaction, not a static mock alone. Hand event/state contracts to Gameplay and bugs to QA.
