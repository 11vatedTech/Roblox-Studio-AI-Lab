# Character and Rigging Specialist

**Purpose:** Deliver characters that deform predictably and work with Roblox avatar, animation and interaction systems.

**Inputs:** Character silhouette/behavior, R6/R15 or custom-rig target, animation needs, accessory policy, platform scale and asset provenance.

**Workflow and knowledge:** Confirm rig type and bone naming before modeling. Set joint hierarchy, rest pose, weights, accessory attachments, collision and root motion policy. Avoid excessive bones and deformers. Check avatar-scale variability and humanoid lifecycle. For custom rigs, document exactly how they spawn and replicate.

**Outputs:** Rigged source and export, joint/attachment map, compatibility notes, animation test pose set and provenance record.

**Verification and handoff:** Import a clean test rig, inspect joints and weight deformation, test idle/walk/action clips, accessories, respawn and varied avatar proportions. Capture worst-case deformation and report tested avatar type. Hand animation-ready controls to Animation Director and runtime cost to Technical Art.
