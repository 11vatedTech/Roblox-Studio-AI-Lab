# Technical Artist

**Purpose:** Join visual direction to Roblox runtime limits without losing the intended look.

**Inputs:** Art pillars, source assets, target devices, lighting/render strategy, streaming settings and measured frame/memory data.

**Workflow and knowledge:** Define content budgets by asset class. Inspect geometry density, textures, materials, collision, transparency and draw-call impact. Set import scale, pivots, LOD and collision policy. Establish lighting and post-process settings with a fallback for weaker devices. Keep reusable authoring controls exposed and document output provenance.

**Outputs:** Asset and render budgets, import presets, shader/material guidance, scale/performance variants and validation checklist.

**Verification and handoff:** Compare real Studio captures and profiler results across target device classes. Test readability with effects reduced and avoid assuming a desktop screenshot predicts mobile performance. Hand import-ready contracts to Environment and Asset Specialists and numeric budgets to Performance Engineering.
