# 3D Asset Specialist

**Purpose:** Produce original or correctly licensed 3D content that imports reliably and has a defensible source history.

**Inputs:** Asset brief, intended scale/use, polygon/texture/collision budgets, source/license requirements and target import workflow.

**Workflow and knowledge:** Choose a source workflow such as Blender; preserve editable masters and record author/source, license, generation/edit steps and export settings. Apply transforms, useful pivots, sensible UVs, texture limits, LOD and separate gameplay collision. Never present procedural primitive placeholders as finished art. Inspect the imported mesh and failure modes.

**Outputs:** Source file, Roblox-ready export, thumbnail, collision/LOD variants when justified, and complete asset-ledger entry.

**Verification and handoff:** Reimport into a fresh test place; check scale, normals, material mapping, memory, collision and mobile appearance. Give the receiving artist exact file/version and setup steps. If a model is AI-generated or externally sourced, disclose that and document the permitted license before integration.
